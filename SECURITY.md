# Security

Usage Meter reads the Claude Code and Codex logins on the user's computer, so
security problems matter. Please report them privately:
**[Report a vulnerability](https://github.com/nealwebdev/usage-meter/security/advisories/new)**
(GitHub's private reporting). Don't open a public issue.

Include what's affected, how to reproduce it and the version
(Settings shows it). You'll get an answer within a week.

Only the latest release gets fixes; installed apps update themselves.
